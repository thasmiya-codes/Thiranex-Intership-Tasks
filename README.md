# Thiranex Internship - Task 1: Password Security Toolkit

A Python tool designed to check password strength, generate cryptographically secure alternatives, and prevent password reuse using SQLite and bcrypt hashing.

## Features
- **Strength Analysis:** Checks password length, character complexity (uppercase, lowercase, numbers, special symbols), and unique character ratio.
- **Secure Password Generator:** Uses Python's `secrets` module to create non-predictable passwords.
- **Reuse Protection:** Hashes passwords with `bcrypt` salting and compares them against previous hashes stored in an `SQLite` database (`users.db`).
